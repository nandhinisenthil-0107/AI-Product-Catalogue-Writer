# AI-Product-Catalogue-Writer
AI-based application to generate product descriptions and catalogue content using Python, Hugging Face Transformers, and Gradio.
AI Product and Catalogue Writer

Project Overview

The AI Product and Catalogue Writer is a Python-based application that generates product descriptions and catalogue content from user-provided product details.

Objectives

- Generate product descriptions automatically.
- Create attractive product catalogue content.
- Reduce the time required for manual product writing.
- Provide an easy-to-use interface for users.

Technologies Used

- Python
- Google Colab
- Pandas
- Hugging Face Transformers
- GPT-2 text-generation model
- Gradio

Features

- Product name and category input
- Price and product feature input
- Target audience selection through text input
- AI-generated catalogue descriptions
- Export catalogue data to CSV

How to Run

1. Open the notebook in Google Colab.
2. Install the required Python libraries.
3. Run the notebook cells in order.
4. Load the AI model.
5. Enter product details into the interface.
6. Generate and save catalogue content.

Sample Input

- Product: Wireless Headphones
- Category: Electronics
- Price: 1499 INR
- Features: Bluetooth, rechargeable battery, noise reduction
- Target Audience: College students

Limitations

The basic GPT-2 model may produce repetitive or incomplete descriptions. Generated content should be checked for accuracy before publication.

Future Enhancements

- Support bulk catalogue generation from CSV files
- Add multiple writing styles
- Improve generated text quality
- Export catalogues in PDF format
